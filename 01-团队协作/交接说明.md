## 5. 工程定位

| 改什么 | 文件 / 函数 |
| --- | --- |
| 入口 | scenes/main.tscn → scripts/main.gd |
| 猪血量、积分、弹卡阈值、结束目标 | data/balance.json |
| 命中、积分、弹卡 | main.gd / strike() |
| 卡片升级入口 | main.gd / apply_card()，当前只返回游戏 |
| 重置 | main.gd / reset_game() |
| 猪、桌面、锤子与界面 | main.gd / _draw()、draw_pig()、draw_hammer() |
| 音效 | assets/hit.wav |

第一轮未拆复杂框架，逻辑在一个脚本里，方便接手和投喂 AI。
如加入升级，要把初始属性保留一份，让 reset_game() 恢复；避免重开后加成残留。
尽量不要改节点名、工程路径和启动脚本。禁止提交 .godot 缓存。

## 9. 替换桌面游戏图标（后续美术）

默认图标文件：03-工程项目/HammerPig/assets/app_icon.png。
制作一张正方形PNG（推荐1024×1024），同名替换即可；无需改玩法代码。
Godot已将项目图标和两个导出预设指向这一个文件，导出时自动生成Windows ICO与Mac ICNS。
然后在Godot“项目 → 导出”重新导出Windows和macOS，更新04目录里的独立程序。
Windows文件图标、Mac应用图标和游戏窗口图标随新包更新；已发出的旧EXE/APP不会自动变。
不要仅把新PNG放在EXE旁边，那不会改变已编译的桌面图标。
默认图标由本次图像生成工具制作，主题为“粉色存钱猪＋锤子＋金币”，后续可替换。
