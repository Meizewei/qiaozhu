# 敲小猪｜计科2403

## 直接玩：不用安装 Godot

- **Windows 64位**：打开 `04-可直接游玩/Windows`，双击带小猪图标的 **敲小猪.exe**。
- **Mac（Intel / Apple芯片）**：打开 `04-可直接游玩/macOS`，双击带小猪图标的 **敲小猪.app**。可把它拖到桌面或“应用程序”。

先完整解压ZIP，再打开游戏，不要在压缩包预览里运行。无需账号、API Key或联网。
本包未做商业开发者签名/公证，系统可能提示来源未知。
Mac首次拦截时，先尝试打开一次，再到“系统设置 → 隐私与安全性 → 仍要打开”确认本应用，之后正常双击。
Windows若出现SmartScreen来源提示，可在确认文件来自本组后，查看“更多信息 → 仍要运行”。
这些说明不要求关闭系统安全防护。

## 修改工程：仅接手开发者需要 Godot

打开 Godot 4.5.1或兼容更新版本 → 导入
`03-工程项目/HammerPig/project.godot` → 编辑 → F5。
每次开发完，到“项目 → 导出”，分别选择 Windows 和 macOS 预设重新导出游戏。
首次导出需安装匹配版本的导出模板。玩家无须安装Godot或模板。
详细接手说明及图标替换方法见 `01-团队协作/交接说明.md`。

## 操作

移动鼠标瞄准，左键敲击。小猪两锤敲碎，每只 +10 分，0.8 秒后补充。
50 / 100 分弹空白卡，点击“收下并继续”或按空格返回。120 分完成本轮。
R 或右上按钮重新开始。空白卡无属性加成；本轮目标是演示闭环，不是最终玩法规则。
